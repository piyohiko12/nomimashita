# のみました

iPhone向けの服薬チェックWebアプリ。GitHub Pagesで静的配信し、薬・服薬記録・テーマは**利用する端末のブラウザー内（IndexedDB）**に保存します。アプリの利用にGoogleやGitHubへのログインは不要です。

## 使い方

1. Safariでサイトを開き、共有メニューから「ホーム画面に追加」します。普段は追加したアイコンから使うことをおすすめします。
2. 「設定 → 薬の登録」で薬名と朝・昼・晩の錠数を設定します。
3. 実際に薬を飲んだら「ホーム」の該当するチェックを押します。
4. 「カレンダー」で日付を選ぶと過去のチェックを追加・取り消せます。変更には確認画面があります。
5. 「設定 → テーマ」でシンプル・ふんわり可愛い・キャラクターを選べます。

日本時間の毎朝05:00に新しい日のチェックへ切り替えます。前日の記録は残ります。合計「1/5回」のような表示はしません。薬名の直後に錠数を表示し、薬ごとに朝昼晩の欄を並べます。

## 保存・プライバシー

- 服薬データをアプリからGoogleやGitHubへ送信する処理はありません。公開されるのはこのソースコードと画像などの静的ファイルです。ホスティング事業者には通常のサイトアクセスが発生します。
- 同じURLでも、他の利用者と記録を共有しません。同じ端末・ブラウザーを使える人は記録を見ることができます。端末を画面ロックしてください。
- 端末間の自動同期はありません。Safariとホーム画面版でも保存領域が別になる場合があります。普段使う方を決めてください。
- ブラウザーのデータ消去・保存領域の整理・端末紛失などで記録を失う場合があります。プライベートブラウズは避け、設定の「使い方・記録のバックアップ」から定期的に書き出してください。
- バックアップの読み込みは端末内だけで行い、アップロードしません。現在の記録を置き換える前に内容を検証し、確認画面を出します。GAS版の同一形式のJSONも読み込めます。
- 初期の薬・服薬記録は空です。`?demo=1`は体験用のメモリー内モードで、閉じると記録が消え、本番の保存領域を変更しません。

## 対応範囲

- ホーム画面への追加、オフライン用アプリファイルの保存に対応。
- **画面を閉じている間のアラーム・プッシュ通知・チェック付きiOSウィジェットは未対応。** 飲む時刻と、画面を開いている間のお知らせを設定できます。音での通知にはiPhoneの時計アプリを併用してください。
- 薬の設定変更は今日から反映し、過去の日の予定とチェック済みのスナップショットを保持します。
- このアプリは記録用であり、服薬量や飲み忘れ時の対応は判断しません。

## 開発・公開

依存ライブラリーやビルド処理なしのHTML/CSS/JavaScript。GitHub Pagesの公開元は `main` ブランチの `/ (root)`。`.nojekyll`で静的配信します。

```sh
node --test core.test.js
```

アプリの更新時には `sw.js` のキャッシュバージョンを上げてください。既存の画面を閉じた後に新版へ切り替わります。Service Workerにはアプリファイルだけを保存し、服薬データをキャッシュしません。

添付のキャラクター画像の権利は権利者に帰属します。このリポジトリは画像の再配布・商用利用に関する権利を付与するものではありません。
