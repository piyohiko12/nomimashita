# おくすり記録

iPhone向けのお薬・体調記録Webアプリ。GitHub Pagesで静的配信し、薬・服薬記録・体調・テーマは**利用する端末のブラウザー内（IndexedDB）**に保存します。アプリの利用にGoogleやGitHubへのログインは不要です。

[アプリを開く](https://piyohiko12.github.io/nomimashita/)

旧名「のみました」「ここちログ」「お薬記録」から改名しました。ホーム画面用アイコンは、添付されたピンクのカプセルと紺色のチェックマークへ変更しています。URL・ホーム画面アプリのID・保存領域の名前は変えず、既存の記録を引き継ぎます。

## 使い方

1. Safariでサイトを開き、共有メニューから「ホーム画面に追加」します。普段は追加したアイコンから使うことをおすすめします。
2. 「設定 → 薬の登録」で薬名と朝・昼・晩の錠数を設定します。
   登録済みの薬は編集画面の「この薬を削除」から削除できます。今日以降の未チェック予定だけを止め、過去と当日の服用済み記録は残します。
3. ホームには日付と薬名が表示され、薬ごとに服用する時間帯のチェックを縦に並べます。日付・文字・アイコンを少し小さく、カードの余白もコンパクトに整えています。実際に薬を飲んだら該当するカードを押します。服用予定のない朝・昼・晩はホームとカレンダー詳細で非表示です。設定では3つの時間帯を選べます。予定を変える前に記録したチェックや過去の服薬履歴は残ります。
4. 薬チェックの下にある「体調の記録をする」から、5段階の顔を選んで保存します。症状は15項目から複数選択でき、トイレ状況（排便）は記号なしの「でた・でていない・未記録」から選べます。メモは任意（1,000文字まで）です。トイレだけを入力する場合も体調の顔を1つ選びます。
5. 「カレンダー」には日ごとの体調を顔スタンプで表示。顔の下は朝（コーラル）・昼（ゴールド）・晩（ブルー）の点で服薬状況を示します。色付きは服用済み、白い点は未チェック、半分の点は同じ時間帯の薬が一部服用済みです。服用予定のない時間帯の点は表示しません。日付を選ぶと症状・メモの確認、体調の編集、過去の服薬チェックの追加・取り消しができます。
6. 「設定 → テーマ」でやさしいコーラル・シンプル・ふんわり可愛いを選べます。「やさしいコーラル」は淡いコーラル色の初期テーマです。廃止済みのテーマ設定が端末に残っている場合も、服薬・体調記録を保ったまま自動的にコーラルへ移行します。

日本時間の毎朝05:00に新しい日のチェックと体調記録へ切り替えます。前日の記録は残ります。体調は1日1件、何度でも編集できます。合計「1/5回」のような表示はしません。薬名の直後に錠数を表示し、薬ごとに朝昼晩の欄を並べます。

## 保存・プライバシー

- 服薬・体調データをアプリからGoogleやGitHubへ送信する処理はありません。公開されるのはこのソースコードと画像などの静的ファイルです。ホスティング事業者には通常のサイトアクセスが発生します。
- 同じURLでも、他の利用者と記録を共有しません。同じ端末・ブラウザーを使える人は記録を見ることができます。端末を画面ロックしてください。
- 端末間の自動同期はありません。Safariとホーム画面版でも保存領域が別になる場合があります。普段使う方を決めてください。
- ブラウザーのデータ消去・保存領域の整理・端末紛失などで記録を失う場合があります。プライベートブラウズは避け、設定の「使い方・記録のバックアップ」から定期的に書き出してください。
- バックアップの読み込みは端末内だけで行い、アップロードしません。現在の記録を置き換える前に内容を検証し、確認画面を出します。GAS版の同一形式のJSONも読み込めます。
- 初期の薬・服薬記録・体調は空です。`?demo=1`は体験用のメモリー内モードで、閉じると記録が消え、本番の保存領域を変更しません。

## 対応範囲

- ホーム画面への追加、オフライン用アプリファイルの保存に対応。
- **画面を閉じている間のアラーム・プッシュ通知・チェック付きiOSウィジェットは未対応。** 飲む時刻と、画面を開いている間のお知らせを設定できます。音での通知にはiPhoneの時計アプリを併用してください。
- 薬の設定変更は今日から反映し、過去の日の予定とチェック済みのスナップショットを保持します。
- このアプリは記録用であり、服薬量や飲み忘れ時の対応は判断しません。顔スタンプは自己評価の記録であり、医学的な判定や診断は行いません。

## 開発・公開

依存ライブラリーやビルド処理なしのHTML/CSS/JavaScript。GitHub Pagesの公開元は `main` ブランチの `/ (root)`。`.nojekyll`で静的配信します。

```sh
node --test *.test.js
```

アプリの更新時には `sw.js` のキャッシュバージョンを上げてください。アプリ一式の保存が完了してから新キャッシュへ切り替わり、次の再読み込みで新版を表示します。Service Workerにはアプリファイルだけを保存し、服薬・体調データをキャッシュしません。更新のためにブラウザーの保存データを削除しないでください。

保存データはバージョン3。バージョン1・2の既存記録は読み込み時の同一トランザクション内で移行します。旧バックアップを読み込めます。昔の体調記録にトイレ状況がない場合は「未記録」とし、「でていない」とは扱いません。旧画面が新しい体調やトイレの記録を誤って消さないよう、バージョン3は旧クライアントでの書き込み対象にしません。
